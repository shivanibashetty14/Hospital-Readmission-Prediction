#Predicting Hospital Readmission Risk Using Machine Learning.
This project develops and evaluates machine learning models to predict hospital readmission risk in diabetics patients using 130 US hospital dataset.
Dataset: Diabetics 130 US hopitals dataset (1999-2008) sourced from  the AIM-AHEAD platform containing 101,766 records and 50 features.
Models used: Logistic Regression, Decision tree, Random Forest and Gradient Boosting
